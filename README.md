# Py | Desktop Utilities

A desktop application built with Python and CustomTkinter that combines a few everyday utilities into a single app.
This was built during my industrial training program

## Features

- QR Code Generator
- Text-to-Speech
- Internet Speed Test
- Light and Dark mode support
- Simple login and registration screen

## Built With

- Python
- CustomTkinter
- Pillow
- pyttsx3
- qrcode
- speedtest-cli
